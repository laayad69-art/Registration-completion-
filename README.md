
# مجمع مدارس علاء زكي زكي — صفحة تسجيل المستويات

صفحة تسجيل إلكترونية أحادية الملف (single-file) لطلاب المرحلتين الأولى والثانية الثانوية،
تتيح اختيار المستويات، رفع صور تأكيد الإتمام، وإرسال البيانات والصور مباشرة إلى قناة
تليجرام مخصصة عبر Bot API.

## الميزات

- **نموذج ديناميكي بحسب المرحلة**
  - الصف الأول الثانوي: مستوى واحد إلزامي + صورة تأكيد.
  - الصف الثاني الثانوي (بكالوريا): اختيار متعدد من ثلاثة مستويات + صورة لكل مستوى.
- **منطقة رفع صور بالسحب والإفلات** لكل مستوى.
- **معاينة فورية** للصورة المرفوعة مع الاسم والحجم وزر حذف.
- **تحقق من الحجم** بحد أقصى 5MB لكل صورة.
- **تحقق من النوع** بقبول الصور فقط.
- **تجزئة كلمة المرور** بـ SHA-256 قبل الإرسال (لا تُرسل كلمة المرور نصاً صريحاً).
- **إرسال إلى تليجرام** عبر `sendMessage` + `sendPhoto` مع تنسيق MarkdownV2.
- **رسائل حالة** للمستخدم: نجاح، فشل، تحقق.
- **تصميم متجاوب** يعمل على الجوال والحاسب.
- **توقيع المطور** أسفل الصفحة.

## التشغيل السريع

### الطريقة الأولى — فتح مباشر

1. احفظ الملف باسم `index.html`.
2. افتحه بأي متصفح حديث.

> ملاحظة: بعض المتصفحات تقيّد `crypto.subtle` على بروتوكول `file://`.
> في هذه الحالة استخدم خادماً محلياً.

### الطريقة الثانية — خادم محلي

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve -l 8080
```

ثم افتح: http://localhost:8080

الطريقة الثالثة — استضافة ثابتة

ارفع index.html إلى أي استضافة ثابتة:

· GitHub Pages
· Netlify
· Vercel
· Cloudflare Pages

الإعدادات

كل الإعدادات في أعلى كتلة <script>:

```javascript
const TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN";
const TELEGRAM_CHAT_ID   = "YOUR_CHAT_ID";
const MAX_BYTES          = 5 * 1024 * 1024;
```

الحصول على Bot Token

1. افتح تليجرام وابحث عن @BotFather.
2. أرسل /newbot واتبع التعليمات.
3. انسخ الـ Token الناتج.

الحصول على Chat ID

1. أضف البوت إلى القناة أو المجموعة المطلوبة، أو ابدأ محادثة خاصة معه.
2. أرسل رسالة تجريبية.
3. افتح:
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
4. ابحث عن "chat":{"id": ...} وانسخ الرقم.

تدفق العمل

```
المستخدم يفتح الصفحة
        │
        ▼
اختيار المرحلة (grade1 / grade2)
        │
        ▼
عرض الحقول المناسبة ديناميكياً
        │
        ▼
اختيار مستوى (أو أكثر) + رفع صورة لكل مستوى
        │
        ▼
إدخال الاسم الرباعي + اسم المستخدم + كلمة المرور
        │
        ▼
التحقق من صحة المدخلات
        │
        ▼
تجزئة كلمة المرور (SHA-256)
        │
        ▼
إرسال الرسالة النصية إلى تليجرام (sendMessage)
        │
        ▼
إرسال الصور واحدة تلو الأخرى (sendPhoto)
        │
        ▼
رسالة نجاح + إعادة تعيين النموذج
```

التحقق من المدخلات

الحقل القاعدة
المرحلة إلزامي — grade1 أو grade2
المستوى (الصف الأول) إلزامي — JavaScript 42
المستويات (الصف الثاني) إلزامي — واحد على الأقل
الاسم الرباعي 4 كلمات على الأقل
اسم المستخدم 3 أحرف على الأقل
كلمة المرور 4 أحرف على الأقل (تُجزّأ قبل الإرسال)
الصور نوع image/*، حجم ≤ 5MB

الأمان

ما تم تطبيقه

· تجزئة كلمة المرور بـ SHA-256 عبر crypto.subtle قبل الإرسال.
· تحقق من نوع الملف (file.type.startsWith('image/')).
· تحديد حجم أقصى لكل صورة.
· تنسيق MarkdownV2 آمن عبر escapeMd لتجنب كسر الرسائل.
· عدم استخدام innerHTML مع بيانات المستخدم إلا في renderPreview (اسم الملف — انظر الملاحظات).

ملاحظات أمنية مهمة

1. التوكن مكشوف في الكود الأمامي.
   أي زائر يمكنه قراءته من ملف HTML. للاستخدام الإنتاجي الجدي يجب:
   · نقل الإرسال إلى backend (Node.js / Python) يخفي التوكن.
   · أو استخدام Cloudflare Worker كوسيط.
2. renderPreview يستخدم innerHTML مع file.name.
   اسم الملف قادم من المستخدم ويمكن أن يحتوي على HTML.
   في بيئة الإنتاج يُستبدل بـ:
   ```javascript
   nameEl.textContent = file.name;
   ```
3. لا يوجد حد معدل (rate limit).
   يمكن إغراق قناة التليجرام برسائل. يُنصح بإضافة:
   · Cloudflare Turnstile
   · حد أقصى لعدد الإرسالات لكل جلسة
4. file:// يعطّل crypto.subtle.
   استخدم خادماً محلياً للتطوير.

الاختبار

اختبار يدوي — قائمة التحقق

☐ فتح الصفحة — تظهر بشكل صحيح بدون أخطاء في Console.
☐ اختيار المرحلة — تظهر الحقول المناسبة فقط.
☐ اختيار JavaScript 42 — يظهر مربع رفع الصورة.
☐ اختيار مستوى واحد من الصف الثاني — يظهر مربع رفع واحد.
☐ اختيار ثلاثة مستويات — تظهر ثلاثة مربعات رفع.
☐ رفع صورة صحيحة — تظهر المعاينة.
☐ رفع ملف غير صورة — تظهر رسالة خطأ.
☐ رفع صورة > 5MB — تظهر رسالة خطأ.
☐ إرسال بدون بيانات — تظهر رسالة تحقق.
☐ إرسال بيانات صحيحة — تظهر رسالة نجاح.
☐ التحقق من وصول الرسالة والصور إلى تليجرام.
☐ التحقق من صحة التجزئة في الرسالة.
☐ اختبار على شاشة جوال — التصميم متجاوب.

اختبار API

```bash
# التحقق من صحة التوكن
curl https://api.telegram.org/bot<TOKEN>/getMe

# التحقق من صلاحية Chat ID
curl https://api.telegram.org/bot<TOKEN>/getChat?chat_id=<CHAT_ID>
```

استكشاف الأخطاء

المشكلة السبب المحتمل الحل
sendMessage: chat not found Chat ID خاطئ أو البوت غير مضاف تحقق من getUpdates وأضف البوت
sendMessage: Unauthorized التوكن خاطئ تحقق من getMe
sendPhoto: PHOTO_INVALID_DIMENSIONS الصورة غير مقبولة بصيغتها حوّل إلى JPG/PNG
crypto.subtle is undefined تعطيل على file:// استخدم خادم محلي
لا تظهر الصورة المعاينة إذن المتصفح أو URL.createObjectURL تحقق من Console
MarkdownV2 error حرف خاص لم يُهرَّب تحقق من escapeMd
